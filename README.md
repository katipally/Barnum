# Agentic CMO

A CMO agent that lives in Snowflake. One orchestrator manages one isolated agent per marketing channel (Google Ads, LinkedIn Ads, billboards, conferences, more later). Each channel agent reads its own raw data shape and reports in one currency: MQL, SQL, cost per SQL, CAC.

Built on Snowflake Cortex Agents and Claude.

Status: hackathon build, in progress.
