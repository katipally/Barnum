**(c) Project description** (≈60 words)
> Agentic CMO is a marketing executive that lives in Snowflake. One Claude orchestrator manages one isolated agent per channel (Google Ads, LinkedIn, conferences, billboards, plus any channel you upload). Each agent turns its platform's raw data into one currency: cost per sales-qualified lead. The CMO moves budget on its own within a limit the CEO sets. Anything bigger becomes a memo with evidence for the CEO to approve.

**(d) Value case**

| | |
|---|---|
| **Metric it moves** | Cost per SQL, and SQLs per marketing dollar, at the same budget |
| **Baseline** | Q4 so far: $63k spent, 140 MQLs, 25 SQLs, **$2,520 per SQL**, fully loaded CAC $56.8k, 8.1-month payback |
| **What the agent finds** | LinkedIn has the *cheapest* MQLs ($276, #1 of 4) but ranks #3 of 4 on cost per SQL ($3,000): only 9% of its MQLs become SQLs. Conferences deliver SQLs at $1,714. An MQL dashboard rewards the wrong channel. |
| **Move** | Move $14k of the remaining $62k into Conferences. Projected SQLs for the rest of Q4 go from 24.9 to 26.5 at the same spend (+6%). That is more than the CEO's 10% autonomy limit ($6.2k), so it waits for approval. |
| **Who funds it** | The CEO/CFO, out of the marketing budget line. The owner is the Head of Marketing or RevOps. |
| **Worth** | For a $1M/yr B2B budget, every 10% gain in SQLs per dollar is worth about **$100k/yr** of equivalent spend. The 2027 plan view also shows the ceiling: $1M buys ~45 customers ($5.5M new ARR) at ~$62k average CAC and an 8.8-month payback. Spend above $1.3M stops paying back within a year. That stops the over-spend a budget meeting never sees. |

**(e) Architecture summary**
```
CEO (web app / CoWork / Claude Desktop via MCP)
        |  approve · reject · ask
FastAPI --PAT--> Snowflake CMO_DB
   CORE     FUNNEL_FACT (union of channel MAP views) · FUNNEL_SV semantic view
            CMO_AGENT (Cortex Agent on Claude) · PROPOSE_REALLOCATION · UNIT_ECON
            ASK_CHANNEL (DATA_AGENT_RUN) · ALLOCATION · DECISION_LOG · ASSUMPTIONS
   CH_<X>   UPLOADS stage · RAW_* (INFER_SCHEMA) · MAP view · semantic view
            REPORT() · RECONCILE() · channel AGENT          (one schema per channel)
```
- **Surfaces:** Cortex Agents (one CMO plus N channel agents, Claude Sonnet 4.5), Snowsight, the Agent Run API with SSE, and our web app.
- **Context:** stages with `INFER_SCHEMA` ingest, and one semantic view per channel plus `FUNNEL_SV`.
- **Toolkit:** Cortex Analyst, and Python stored procedures as custom tools (`PROPOSE_REALLOCATION`, `UNIT_ECON`, `RECONCILE`, `ASK_CHANNEL`).
- **Intelligence:** `AI_COMPLETE` with structured output. Claude writes each new channel's raw-to-funnel SQL.
- **Action:** governed write-back to `ALLOCATION` and `DECISION_LOG` through approved memos.
- **Isolation:** a channel agent's tools touch only its own schema, and the CMO reads only `CORE`.

**(f) Build story** (≈80 words)
> We split the build across parallel agents. Claude Code _(add CoCo if you used it)_ wrote the Snowflake SQL, the procedures and the FastAPI backend from one design doc. A second set of Claude Code agents built the CEO web app against a mock with the same API contract, so both halves met in the middle. Claude also writes production code at run time: every new channel's mapping SQL is generated by `AI_COMPLETE`, checked by a validator (spend must reconcile to $1, MQL ≥ SQL ≥ won) and retried on failure.

## 2. The case for each criterion

### Impact: "your best channel is your worst"
- **Hook:** LinkedIn ranks #1 on cost per MQL and #3 of 4 on cost per SQL. A CEO looking at MQL dashboards funds the trap; this agent catches it in its first review (asserted in `test_linkedin_is_the_trap`).
- **Money sentence:** "Same $62k, more pipeline, and the CEO approved it in one click."
- **Stop-loss:** the 2027 plan tells the CFO the budget ceiling where the last customer stops paying back. Few marketing teams can answer that.
- **Proof on screen:** the strip before and after approving the memo; projected SQLs go up (`test_reallocation_memo_and_approval`).

### Demo: one storyline, three beats, no detours
1. **Review.** `POST /q4/review` streams: the channel agents report *in parallel* (visible delegation events), then the CMO writes the memo.
2. **Decide.** The memo is above the 10% autonomy limit → pending → the CEO approves → the projection updates.
3. **Plug in.** Upload a webinar CSV live. Claude writes the mapping, the validator reconciles spend to $1, the channel agent is provisioned, and the next review includes it with no code change.

Rehearse with `tests/smoke.sh 3`. Have `POST /demo/reset` ready. Keep a screen recording as the fallback if Snowflake is slow.

### Creativity
- **Org chart, not chatbot.** Agents are organised like a marketing department. Each channel lead knows only its own data, and the CMO only sees reports in one currency.
- **Self-extending.** A new channel is a CSV. Claude writes, and gets tested on, the SQL that joins it to the company's funnel.
- **Bounded autonomy.** The CEO sets a percentage, not rules. Below it the agent acts; above it the agent asks.

### Craft with Snowflake and Claude
- **Numbers from tools, words from Claude.** Every API response carries the SQL behind it. Claude never computes a figure.
- **Most of the guide's dimensions are used:**
  - Cortex Agents: N+1 of them
  - Semantic views and Cortex Analyst
  - custom procedure tools and governed write-back
  - `DATA_AGENT_RUN` for agent-to-agent calls
  - `AI_COMPLETE` structured output
- **Engineering hygiene:** the validator plus retries; per-channel schema isolation; `RECONCILE()` with a diff of exactly zero; tests pinned to the live DB; a smoke test run 3× in a row.
- **Cheap extra points before the freeze, in order:**
  1. **Evals:** 5 golden questions in Cortex Agent evaluations, e.g. "cost per SQL for conferences?" → $X. One screenshot.
  2. **Observability:** a Snowsight trace of one `/q4/review`, showing the CMO → channel delegation. One screenshot.
  3. **MCP:** expose `CMO_AGENT` through the Snowflake-managed MCP server and ask it a question from Claude Desktop. One video shot.
